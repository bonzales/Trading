# Reference — Comandi Telegram

> Modalità: *reference*. Solo i fatti. Bot owner-only (eredita Kraken).

| Comando                                   | Effetto                                  |
|-------------------------------------------|------------------------------------------|
| `/backtest <strat> <strum> <tf> <periodo>`| Lancia un backtest, output in `raw/`     |
| `/status`                                 | Stato del bot e posizioni aperte         |
| `/report`                                 | Metriche correnti (PF, DD, equity)       |
| `/paper_start <strat> <strum>`            | Avvia paper trading su demo              |
| `/pause`                                  | Mette in pausa l'operatività             |
| `/resume`                                 | Riprende                                  |

Timeframe ammessi: `M1 M5 M15 M30 H1 H4 D1`.
Periodo: es. `3y`, `18m`, `500d`.
