# Reference — Metriche di performance

> Modalità: *reference*. Definizioni rapide delle metriche nei report.

| Metrica          | Cosa misura                                              |
|------------------|----------------------------------------------------------|
| Profit Factor    | profitti lordi / perdite lorde. >1 in utile; ~0.9 perde. |
| Sharpe           | rendimento aggiustato per la volatilità.                 |
| Max Drawdown     | la peggiore caduta picco-valle dell'equity.              |
| Win rate         | % di trade vincenti (da sola dice poco).                 |
| N. trade         | dimensione del campione (pochi trade = poco affidabile). |
| Esito OOS        | in-sample vs out-of-sample: il verdetto che conta.       |

Nota: un win rate alto con profit factor basso può comunque perdere. Il segnale che
conta davvero per promuovere è l'**esito out-of-sample**.
